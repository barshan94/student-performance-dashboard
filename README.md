Student Performance & Academic Analytics Dashboard

An Excel-based academic analytics project for analyzing student performance across Grades 3–7.

Project Overview

This project organizes student academic data into a dashboard designed to help educators review class performance, assessment results, attendance, and grade distribution.

Dashboard Features

- Student information and academic records
- Attendance tracking and absence summaries
- Quiz marks and class averages
- Highest and lowest marks
- Passing-rate analysis
- Grade distribution visualization
- Class-wise performance summaries
- Homework tracking
- Overall academic performance analysis

Tools

- Microsoft Excel
- Spreadsheet formulas and data visualization

Purpose

The goal of this project is to demonstrate how spreadsheet-based analytics can turn academic records into structured performance summaries that support classroom monitoring and educational decision-making.

Repository Contents

- Excel workbook containing the Student Performance & Academic Analytics Dashboard

Privacy

The original workbook contains student information. This repository is private, and identifiable student data should not be made publicly accessible.

Author

Created as an educational analytics and data analysis portfolio project.
